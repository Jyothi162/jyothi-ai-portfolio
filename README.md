# Jyothi Rajan — AI Engineer Portfolio

Modern responsive portfolio built with React, Vite, and Tailwind CSS.

## Run locally

Requires Node.js 18+.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (usually http://localhost:5173).

## Build

```bash
npm run build
```

## Deploy to Vercel

Push the repository to GitHub, import it into Vercel, and use the default Vite settings (`npm run build`, output directory `dist`).

## Before publishing

- Check all project descriptions and links.
- Add your verified LinkedIn profile, preferred public contact method, and current CV.
- Replace the Enterprise Agentic RAG placeholder with a link when its repository is ready.
- Add actual project screenshots and validated metrics when available.
